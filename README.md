# Close the Loop — The Climate Fix Is a Pollution Fix

A one-page digital report from **H Heuristics** on sustainability, climate change, and the pollution cycle. Built with Veles (Fable-5).

**Live claim:** climate change and the pollution cycle are one feedback loop powered by material throughput. Breaking the loop cuts both carbon and pollution in the same motion.

## File

- `index.html` — the entire report. Self-contained single page (inline CSS + Chart.js from CDN), deploy-ready for GitHub Pages.

## Deploy on GitHub Pages

1. Push to the `main` branch (already done via this repository).
2. In the repo: **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. GitHub builds the page at:
   `https://hunterhghs.github.io/Sustainability-to-address-climate-change-and-the-pollution-cycle/`

No build step is required — the site is static HTML.
